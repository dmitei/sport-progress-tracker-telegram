# Трекер прогресса — Telegram Mini App + бот

Личный трекер в Telegram: замеры тела (вес и обхваты) с графиками и дневник питания с подсчётом КБЖУ и собственной базой продуктов.

## Возможности

**Замеры**
- вес, обхват груди, талии (выше / на уровне / ниже пупка), таза, бедра, бицепса
- изменение относительно прошлого замера
- график по любой метрике: 7 дней, 30 дней, 3 месяца, всё время
- история записей с удалением

**КБЖУ**
- свои продукты: название и калории/белки/жиры/углеводы на 100 г
- продукты сохраняются в личную базу, дальше их можно искать и добавлять в пару нажатий
- дневник по датам, итоги дня по калориям и БЖУ

Данные хранятся в Telegram CloudStorage (привязаны к аккаунту, доступны на всех устройствах). Вне Telegram приложение работает на localStorage.

## Структура

| Файл | Назначение |
|------|-----------|
| `index.html` | Mini App: один файл на чистом JS, без сборки |
| `bot.py` | Бот на aiogram 3: кнопка запуска приложения и кнопка меню |
| `requirements.txt` | Зависимости бота |

## Установка

### 1. Опубликуй Mini App

1. Загрузи `index.html` в корень репозитория на GitHub.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Получишь ссылку вида `https://username.github.io/repo/`.

### 2. Создай бота

1. В [@BotFather](https://t.me/BotFather): `/newbot` и получи токен.

### 3. Запусти бота

```bash
pip install -r requirements.txt

export BOT_TOKEN="токен_от_BotFather"
export WEBAPP_URL="https://username.github.io/repo/"

python bot.py
```

Windows (cmd):

```bat
set BOT_TOKEN=токен_от_BotFather
set WEBAPP_URL=https://username.github.io/repo/
python bot.py
```

## Команды бота

| Команда | Действие |
|---------|----------|
| `/start` | приветствие и кнопка «Открыть трекер» |
| `/help` | краткая справка |

Дополнительно бот ставит постоянную кнопку меню «Прогресс» рядом с полем ввода.

## Хранение данных

Telegram CloudStorage ограничивает значение 4096 символами, поэтому приложение режет данные на части по 3500 символов и собирает обратно при загрузке. Лимит ключей (1024) при личном использовании не достигается.

Бот данные не хранит и не видит, поэтому база данных не нужна. Работать он должен постоянно, чтобы отвечать на `/start`. Подойдёт VPS, Railway, Fly.io или любой хостинг с Python.

## Требования

- Python 3.9+
- aiogram 3.4+
- Telegram с поддержкой Bot API 6.9+ (для CloudStorage)
